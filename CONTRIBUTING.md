# Contributing

Keep personal avatars, wearables, fitted meshes, textures, and renders out of the repository. Contributions should contain add-on code, tests, documentation, or animation files with documented redistribution rights.

For code changes, run `python scripts/check.py` and the Blender tests related to the change. For clothing-fit or retargeting changes, describe the source/target rig types and the poses or frames reviewed.

For animation contributions, include source, author, license, attribution text, FPS, frame range, loop status, root-motion status, and category. Do not submit files extracted from games or marketplaces unless their license explicitly permits redistribution.
