# Bundled motion assets

`manifest.json` lists animation clips that may legally be redistributed with Wardrobe Bridge. The `Defold - Quaternius UAL` folder contains 45 CC0 motions converted from the GLB used by Defold's 3D Animations example.

Before adding another clip, record its author, source URL, license, required attribution, category, FPS, frame range, loop status, and root-motion status. A local catalog marked `UNVERIFIED_LOCAL_ONLY` is useful for testing but must not be copied into a public release.
