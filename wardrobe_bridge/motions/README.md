# Bundled motion assets

`manifest.json` lists animation clips that may legally be redistributed with Wardrobe Bridge. Keep source downloads and personal animation collections outside this directory.

Before adding a clip, record its author, source URL, license, required attribution, category, FPS, frame range, loop status, and root-motion status. A local catalog marked `UNVERIFIED_LOCAL_ONLY` is useful for testing but must not be copied into a public release.
